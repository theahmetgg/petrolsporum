# BÖLÜM 5: YAZILIM MİMARİSİ & WEB ENTEGRASYONU (TECH STACK)

Web sürümünü de geliştireceğiniz için **React Native (Expo)** ve ortak TypeScript katmanı seçilmiştir.

### Teknoloji Tercihleri:
* **Mobil Çatı:** React Native (Expo SDK, Expo Router - Dosya tabanlı rota yönetimi).
* **Web (karar, 18 Kasım 2026):** Ayrı Next.js uygulaması (Batman360'taki gibi); mobil ile ortak TypeScript tipleri.
* **Stil Katmanı:** NativeWind (Tailwind CSS v4) - Mobil ve Web'de aynı class'lar.
* **State Yönetimi:** Zustand (Global hafif state), TanStack Query (API önbellek & veri yönetimi).
* **Canlı İletişim:** Socket.io-client (Anlık skor, canlı anlatım ve ışık şovu senkronizasyonu).
* **İkonlar:** Lucide Icons & @expo/vector-icons.
